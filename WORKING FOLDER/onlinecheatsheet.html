Working With Breakpoints, Containers, Columns, and the Grid System

View this guide: Bootstrap Guide: Containers, Columns, & the Grid System

Creating a Simple Container With 2 Columns

To use Bootstrap to create a 2-column design, you need to create a container, add a row within that container, and then add 2 columns within that row. 

Here's how that might look:

<div class="container-fluid">
  <div class="row">
      <div class="col-6">Item 1</div>
      <div class="col-6">Item 2</div>
  </div>
</div>

Notice:

  • I am using a container-fluid, which takes up the full width of the screen.
  • Columns are nested within rows, rows are nested within containers
  • Each column has a class of col-6. That means each column (col) will take up 6 columns of the 12 column grid. This creates a 2-column layout where each column takes up 50% of the screen.
  • In this example above "Item 1" is on the left and "Item 2" is on the right.
  • If you wanted these 2 columns stacked on a small screen, you would add a "sm" breakpoint to your cols. Like so: 
<div class="container-fluid">
  <div class="row">
      <div class="col-sm-6">Item 1</div>
      <div class="col-sm-6">Item 2</div>
  </div>
</div>

Modifying Bootstrap With CSS

You can modify any bootstrap element with CSS by adding a class and styling it or giving it an ID.

Example:

Here is a Bootstrap container with an additional class, "topper."

    <div class="container topper">
    </div>

And here's how I might style it via a CSS rule. Notice because topper is a class, I have used a period in front of my selector.

.topper{
    background-color:beige;
}

In this example, I am styling all div elements with the class of topper.

Another example:

Here is a Bootstrap HTML element (container-fluid) that has a unique ID. 

<div class="container-fluid" id="footer">
Footer information
</div>
#footer {
    background-color:black;
}

In this example, I created a CSS rule to style the footer. I am using an ID as the selector, so it begins with a #.

Adding a Navigation

To add a navigation to your online portfolio, you can use the Bootstrap grid system. 

Here's helpful code for creating a simple horizontal nav:

      <div class="container-fluid" id="navigation">
            <div class="row">
                <div class="col-4">
                    <h3>Item 1</h3>
                </div>
                <div class="col-4">
                    <h3>Item 2</h3>
                </div>
                <div class="col-4">
                    <h3>Item 3</a></h3>
                </div>
            </div>
        </div>


Responsive:

Make this responsive by having the navigation items stack on the small screen:

      <div class="container-fluid" id="navigation">
            <div class="row">
                <div class="col-sm-4">
                    <h3>Item 1</h3>
                </div>
                <div class="col-sm-4">
                    <h3>Item 2</h3>
                </div>
                <div class="col-sm-4">
                    <h3>Item 3</a></h3>
                </div>
            </div>
        </div>

Styling:

  • Style your navigation elements in your style.css files to make it match your design. You can do this by creating a class like "nav":
      <div class="container-fluid" id="navigation">
            <div class="row">
                <div class="col-sm-4 nav">
                    <h3>Item 1</h3>
                </div>
                <div class="col-sm-4 nav">
                    <h3>Item 2</h3>
                </div>
                <div class="col-sm-4 nav">
                    <h3>Item 3</a></h3>
                </div>
            </div>
        </div>

 

Linking:

To get your navigation items to link to the sections of your online portfolio, you will need to do 2 things:

Give IDs to the elements that you want to link to. Example:

<h3 id="experience">Experience</h3>

Link to those elements in the navigation. Like so:

<a href="#experience">Experience</a>

Styling links:

To style the links in your navigation, you'll want to use the following selector:

.nav a {
}

In the code above, the selector is targeting any "a" tags in any "nav" class.

To adjust the styling of the links on hover, you will want to use the following selector:

.nav a:hover {
}

Adding a Headshot

  • Download a headshot image to your computer, save it in the online-portfolio-project folder.
    • Note: The size of the image doesn't really matter, but if you want your headshot to be a square or circle, you will need to work with an image that is a square. You'll have to crop your image to be square before you get started. If your headshot image is a rectangle or oval, start with a rectangle.

Add Image to HTML

  • Add the image to your HTML where you want your headshot to appear. Give it an ID of "headshot". Like so:
<img src="331111-5d4047f865b00.jpg" id="headshot">
  • For the code above to work, your headshot image needs to be saved in the same folder as your HTML document and you need to have the exact filename correct in the code.

Style Image in CSS

  • Head over to your CSS file and add a CSS rule for your headshot. Like so:
#headshot {
}
  • Note that the CSS rule above is targeting your HTML tag that has the ID of "headshot" by using #headshot as the selector.
  • You'll definitely want to Size your image in your CSS rule. You can set the width to be a certain measurement and your height will automatically adjust. You have 2 options:
    • Add width:100% as a declaration. Your image will take up 100% of the <div> tag it's inside. The benefit of this approach is that the size of your image adjusts responsively. 
    • Add a fixed width like width:300px. The benefit of this approach is that the size of your image stays consistent across all screen sizes
  • Other CSS declarations you may want to include to style your headshot include:
    • Border (helpful guide)
    • Border-radius (this adds rounded edges or creates a circle) (helpful guide)
    • Padding or Margin (helpful guide)
      • Warning: Adjusting your padding might mess up your border or border-radius, so consider a margin.

Example:

Code:

#headshot {
    width:100%;
    padding:0px;
    margin:20px 0px 20px 40px;
    border-radius: 500px;
}

Adding a Background Image

Let's say you want a background image behind my your headshot or other information. Here's what you will have to do:

  • Download a background image to your computer, save it in the online-portfolio-project folder.
    • Note: You MUST have permission to use the image. (It can be a photo you took or you can check Wikimedia Commons or Public Domain Images.)
    • The size of the image doesn't really matter, but you want it to be very big and you want it to work as a horizontal rectangle.
  • Create or identify a container for your background image in the HTML. For example, if you want your background image to show up behind your topper, add an ID of "topper" to the container or container-fluid where your topper content lives. Like so:
<div class="container-fluid" id="topper">
TOPPER CONTENT WOULD GO HERE
</div>
  • Once you do that, you can add your background image in a CSS rule. Like so:
#topper {
    background-image: url(taylor-heery-hv2yJQdxyi0-unsplash.jpg);
    background-size:cover;
}
  • In the example above, I have a declaration for background-size:cover. The background-size property lets your size your background image. The "cover" value means the image will stretch the full width of the container.
  • Here is a helpful guide on background images. 
  • Here is a helpful guide on the background-size property.
  • You may want to use the background-position property to get the part of the background image you want to show up.

Adding an Overlay on a Background Image

  • You may also want to add an overlay over a background image to put text on top. This is a little tricky. You basically have to add a opaque background color to a container that is on top of your background image. That way you will have:
    • The background image
    • Under a container with a background color
    • An opacity applied to that background color that lets the image show through
  • First, create the CSS rule for the overlay. You can't simply use the typical background color declaration (ex. background-color:black). You have to use the RGB value of the color. That's the only way to add an opacity to the color. More on that here (scroll to the section on opacity). 
  • In the end, here's what your code might look like:
.overlay {
    background: rgba(0, 0, 0, 0.35);
}
  • In this example, the overlay class is a black color that is 35% opaque.
  • You have to then apply this opacity. You can apply it to the container, row, or column that the content is within. Example:
<div class="row overlay">
</div>

Or

<div class="col-4 overlay">
</div>
  • In the above examples, the HTML tags have two classes. They are separated by a space.
  • You may need to add a height to your overlay CSS rule to make it match the height of your background image.

Adding a Button

First, add the button tag to your HTML document where you want your button to go. Then give it an ID so you can style it in your CSS. Like so:

 <button id="button"><a href="#">Hire Me</a></button>

In the example above, my button text is "Hire Me" and my button ID is "button". I also included a placeholder link. (You're going to want your button to link somewhere.)

After adding the button and link to your HTML, you can style it in your stylesheet using CSS rules.

You'll definitely want to adjust the size, background-color, border, border-radius, and the styling of your linked text. Here's an example of a styled button:

#button {
    background-color:#E56B6F;
    border:0px;
    border-radius: 10px;
    padding:10px 30px 10px 30px;
    text-transform:uppercase;
    margin:10px;
}

#button a {
    color:white;
    text-decoration: none;
}

In the example above:

  • I am targeting the button by using the ID I gave it (button).
  • I added a background-color, removed the border, and added rounded corners to my button (using the border-radius property).
  • I also added padding to my button, and more padding (30px) on the sides than on the top and bottom (10px).
  • I transformed the text to be uppercase.
  • I also added a margin around the whole thing to separate it from other elements.

Lastly, I added a separate CSS rule for the linked text within my button. To do this I used two selectors (#button and a). I put a space between them. In this rule, I am telling the stylesheet to look for any "a" tags within the "#button" tag and apply the following styles:

  • Make the text white
  • And remove the underline (that's what text-decoration none does).

Linking your button:

It's important to have your button do something when users click on it. Here's a button with no click action:

 <button id="button">Contact Me</button>

To make the button go somewhere, we need to add a small bit of javascript code. We will use the onclick function and then window.open method.

                    <button onclick="window.open('mailto:srdecker@umd.edu')">Email button</button>
                    <button onclick="window.open('https://www.google.com')">Link button</button>

In the first example above, we are linking people to a black email addressed to you. In the second example, we are taking people to a link.

 

Handling Spacing

To adjust the spacing between items in your portfolio, use the margin property in your CSS.

As you will remember from the CSS box model, the margin is the space between objects.

This helpful guide walks you through using margins: https://www.w3schools.com/css/css_margin.asp.

Are you finding you have a little bit of extra padding on your Bootstrap columns that you want to get rid of?

You need to remove the default padding on the columns.

To do this, add a second class to the column, something like "fullwidth" like so:

                <div class="col-sm-4 fullwidth">

And give that class the following rule:

    .fullwidth {
        padding: 0px;
    }

 

Centering

To center text and other elements, use this CSS declaration:

text-align:center;

In order to center an element, you will have to use the following CSS declarations:

button 
{
    display:block;
    margin:auto;
}

In this example, the button will be centered because margin is 0 and it is set to display as a block.

Alternatively, if neither of those options work, you may need to use this CSS declaration:

 justify-content: center;
